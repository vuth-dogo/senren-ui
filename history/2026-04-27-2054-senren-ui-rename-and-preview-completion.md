## Goal

Rename the gem from `senren-rails` to `senren-ui`, complete live previews in

## Changes Made

- Renamed the gemspec from `senren-rails.gemspec` to `senren-ui.gemspec`.

  and namespace as `senren/rails` and `Senren::Rails`.
- Updated `apps/site` and `apps/todolist` Gemfiles to use:

  ```ruby
  gem "senren-ui", path: "../../senren-rails", require: "senren/rails"
  ```

- Regenerated Bundler lockfiles for the gem, docs site, and todolist app.
- Updated `LlmsWriter` and regenerated `public/llms.txt` and
  `public/llms-full.txt` in both apps so generated headers now say
  `Generated by senren-ui`.
- Promoted these non-SaaS, non-Rich Content stubs to implemented components:
  Breadcrumb, Tabs, Accordion, Collapsible, Sidebar, ThemeToggle,
  ShortcutKey, Table, Pagination, Progress, Clipboard, Combobox, Calendar,
  DatePicker.
- Replaced placeholder Stimulus controllers for promoted interactive
  components with real local behavior:
  tabs, accordion, collapsible, sidebar, theme toggle, clipboard, combobox,
  calendar, date picker.
- Added curated `apps/site` live preview partials for all promoted components.
- Re-ran `senren-rails/bin/seed_site.rb` to copy updated templates and
  registry metadata into `apps/site`.
- Re-ran `senren-rails/bin/seed_preview` to refresh preview generated
  metadata after the gem rename.
- Updated active planning/master docs to teach `senren-ui` as the gem name.
  Historical history files were left unchanged.
- Replaced the default `apps/todolist/README.md` with local dogfood commands.

  seed scripts, and docs-site Tailwind `@source` paths already depend on it.
  The package identity is now `senren-ui`.
- Left historical history files unchanged even though they mention the old gem
  name; they remain accurate records of prior sessions.
